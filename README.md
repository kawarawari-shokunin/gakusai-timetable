# gakusai-timetable# 
# TBA学祭ステージ2026 タイムテーブル #

TBA学祭ステージ2026（10/23〜10/25）のプログラム表をWebブラウザ上で閲覧するためのアプリケーションです。GitHub Pagesを利用して静的にホスティングされています。

## ✨ 主な機能

* **現在時刻との連動**: ページにアクセスした際、現在時刻を取得して「現在放送中（ON AIR）」または「準備中（NEXT）」の企画へ自動的にスクロールします。
* **リアルタイムステータス表示**: 時間の経過に合わせて「ON AIR」表示や、番組間の転換時間を示す専用の「準備中カード」が自動で切り替わります。
* **タグによる絞り込み**: 「ラジオ」「企画」「音楽」などのタグボタンをクリックすることで、該当する番組だけをフィルタリング表示できます。
* **日跨ぎの自動遷移**: その日の全プログラムが終了すると、自動的に翌日のタブに切り替わります。

## 📁 ファイル構成

* `index.html`: アプリのメイン画面（UIの枠組み）
* `style.css`: レスポンシブ対応のデザイン・レイアウト
* `app.js`: 描画、現在時刻の判定、スクロールなどのシステム制御ロジック
* `data.json`: 番組表の全データ（スプレッドシートから生成）

## 🚀 ローカルでの動作確認方法

このアプリは `data.json` を非同期で読み込む（`fetch`APIを使用する）ため、単純に `index.html` をダブルクリックしてブラウザで開く（`file://`プロトコル）と、ブラウザのセキュリティ制限（CORSエラー）によりデータが表示されません。

ローカルで動作確認・開発を行う場合は、以下のいずれかの方法で簡易ローカルサーバーを立ち上げてください。

* **VS Codeを使用する場合**: 拡張機能「Live Server」をインストールし、`index.html` を右クリックして「Open with Live Server」を選択します。
* **Pythonを使用する場合**: ターミナルでこのフォルダを開き、`python3 -m http.server`（Mac/Linux）または `python -m http.server`（Windows）を実行後、ブラウザで `http://localhost:8000` にアクセスします。

## 🕒 現在時刻のテスト（デバッグ）方法

学祭当日以外の日に「〇〇日の〇〇時の動作」を確認したい場合は、`app.js` の上部にある `DEBUG_NOW` 変数に任意の時刻を設定してください。

```javascript
// app.js 10行目付近
// 例: 2日目の12:15の挙動を確認したい場合
const DEBUG_NOW = "2026-10-24T12:15:00+09:00"; 

// 本番環境（実際の現在時刻を使う）に戻す場合は空文字列にします
const DEBUG_NOW = ""; 
```

## 📝 番組表データ (`data.json`) の更新手順

番組表の追加・修正・タグの変更などは、専用のGoogleスプレッドシートで行います。

1. スプレッドシート上でデータを編集する。
2. スプレッドシートからデータをCSV形式でダウンロードする。（`ファイル` > `ダウンロード` > `カンマ区切り形式 (.csv)`）
3. CSVデータをJSON形式の配列に変換する。（※ChatGPTやGeminiなどのAIにCSVを貼り付けて「この形式のJSONにして」と依頼するのが最も簡単です）
4. 変換されたJSONデータで、このリポジトリの `data.json` の中身を上書き保存し、GitHubへプッシュ（コミット）する。
