# TBA学祭ステージ2026 タイムテーブル Webアプリ

GitHub Pagesで動作する、レスポンシブ対応の番組表Webアプリです。

## 主な機能
*   **現在時刻の自動追従**: ページを開いた際、現在放送中の番組や、次に控えている番組（準備中）の箇所まで自動でスクロールします。
*   **番組状態のリアルタイム更新**: 放送中の番組には「ON AIR」バッジがつき、転換中の時間帯には「⏳ 現在、ステージ準備中です」という案内カードが自動で表示されます。
*   **日跨ぎの自動遷移**: 1日の最後の番組が終了すると、自動的に翌日のタブに切り替わります。
*   **タグフィルター**: データに登録されたタグ（例:「ラジオ」「音楽」など）から自動でフィルターボタンを生成し、番組を絞り込み表示できます。

## データの更新方法
番組表の内容を変更したい場合は、以下の手順で `data.json` を更新してください。

1.  専用のスプレッドシートに番組情報（日付、開始・終了時刻、タイトル等）を入力します。
2.  スプレッドシートの「ファイル」>「ダウンロード」>「カンマ区切り形式 (.csv)」からCSVをダウンロードします。
3.  ダウンロードしたCSVを、Pythonスクリプト等の変換ツールを用いて本アプリの `data.json` のフォーマットに変換します。
4.  出力された新しい `data.json` をこのリポジトリに上書きプッシュすると、アプリに即座に反映されます。

## 動作確認・テスト（デバッグモード）
本番環境に影響を与えずに、任意の時間にジャンプしたり時間の進みを早くしたりして、UIの挙動（ON AIRの切り替わり等）をテストできます。

*   **使い方**: アプリのURLの末尾に `#debug` または `?debug=true` を付けてアクセスします。
    *   例: `https://[あなたのGitHubユーザー名].github.io/[リポジトリ名]/#debug`
*   右下に「🛠 デバッグツール」パネルが表示されます。
*   「開始時刻」を入力し、「30倍速で進める」にチェックを入れて「適用」を押すと、指定した時間から高速でアプリ内の時計が進みます。
